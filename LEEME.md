# Invitación de cumpleaños — Yasemin (12 años) 🎀

## Qué tenés que completar

Abrí `index.html` con cualquier editor de texto (o el editor de código que uses) y buscá estos 5 lugares para poner los datos reales:

1. `id="dato-fecha"` → la fecha del cumple
2. `id="dato-hora"` → el horario
3. `id="dato-lugar"` → el lugar/dirección
4. `id="dato-rsvp-fecha"` → hasta cuándo confirmar
5. `id="dato-telefono"` → tu número de WhatsApp (con código de país, ej: `+54 9 381 1234567`) — al completarlo, el botón "Confirmar asistencia" abre WhatsApp automáticamente con un mensaje ya armado.

## Cómo publicarla

### Opción A: GitHub Pages (gratis, resultado idéntico a este diseño)
1. Creá un repositorio nuevo en GitHub y subí estos 3 archivos/carpetas (`index.html`, `css/`, `js/`).
2. Andá a **Settings → Pages**, elegí la rama `main` y carpeta `/root`.
3. GitHub te da un link público tipo `https://tuusuario.github.io/tu-repo/` — ese es el que compartís por WhatsApp.

### Opción B: Canva
Canva no permite importar un archivo HTML directamente en su editor de "Sitios web" — ese editor funciona solo con bloques de arrastrar y soltar. Dos caminos si querés usar Canva igual:
- **Recrear el diseño a mano en Canva** usando esta paleta y esta estructura como guía (colores, textos e íconos ya están definidos abajo).
- **Publicar con GitHub Pages y enlazar** esa URL desde un botón o QR dentro de un diseño de Canva (por ejemplo, una tarjeta que decís "tocá para ver la invitación").
